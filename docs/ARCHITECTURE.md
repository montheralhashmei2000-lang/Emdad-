# نظام الإمداد والتموين - الهيكل المعماري

## 1. نظرة عامة
نظام متكامل لإدارة سلسلة الإمداد يشمل:
- إدارة المخزون والعهد
- المعاملات المخزنية (استلام، صرف، تحويل، مرتجع)
- إدارة الجهات المستفيدة والموردين
- نظام التقارير والإشعارات
- مزامنة مع الخادم المركزي

## 2. المكونات الرئيسية

### 2.1 الطبقات الأساسية
1. **واجهة المستخدم (UI Layer)**:
   - PySide6 (Qt for Python)
   - دعم كامل للغة العربية (RTL)
   - تصميم ERP احترافي

2. **منطق العمل (Business Logic)**:
   - خدمات متخصصة لكل وحدة وظيفية
   - قواعد التحقق من الصحة
   - معالجة الأحداث والعمليات

3. **الوصول للبيانات (Data Access)**:
   - SQLAlchemy ORM
   - SQLite (قابلة للترقية لـ PostgreSQL)
   - نمط Repository

### 2.2 الوحدات الوظيفية

#### الوحدات الأساسية:
- **المصادقة والصلاحيات** (Authentication & RBAC)
- **إدارة الأصناف** (Items Management)
- **المستودعات** (Warehouses)
- **المخزون** (Inventory)

#### المعاملات:
- **الاستلام** (Receive)
- **الصرف** (Issue)
- **المرتجعات** (Returns)
- **التحويلات** (Transfers)
- **الجرد** (Stocktake)

#### الإدارة:
- **الجهات المستفيدة** (Beneficiaries)
- **الموردون** (Suppliers)
- **الاستحقاقات** (Entitlements)
- **التفريدة** (Tafreeda)

#### النظام:
- **التقارير** (Reporting)
- **الإشعارات** (Notifications)
- **المزامنة** (Sync)
- **الإعدادات** (Settings)

## 5. قواعد التصميم
1. **الفصل بين الطبقات**:
   - لا تتحدث UI مباشرة مع قاعدة البيانات
   - الخدمات لا تعرف تفاصيل الواجهة

2. **إدارة الحالة**:
   - حالة التطبيق تدار في طبقة الخدمات
   - النماذج تعكس حالة البيانات فقط

3. **المعاملات**:
   - كل عملية مخزنية هي معاملة منفصلة
   - تدعم التراجع عند الفشل

4. **الأمان**:
   - التحقق من الصلاحيات على مستوى الخدمة
   - تسجيل كافة عمليات التعديل
