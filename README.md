# Emdad- (Mobile)

مشروع Flutter - scaffold لتطبيق أندرويد.

الوصف
------
هذا المستودع يحتوي على scaffold لتطبيق موبايل مبني بـ Flutter مهيأ للعمل على أندرويد. يتم إنشاؤه ضمن الفرع `feature/mobile-scaffold` ويحتوي على ملفات أساسية لتشغيل التطبيق محليًا.

تشغيل محليًا
-------------
المتطلبات:
- تثبيت Flutter SDK (https://flutter.dev)
- جهاز Android متصل أو محاكي

الأوامر الأساسية:
1. استرجاع الحزم:

   flutter pub get

2. تشغيل التطبيق على الجهاز/المحاكي:

   flutter run -d android

3. لبناء ملف APK:

   flutter build apk --release

ملاحظات
-------
- هذا التهيئة خفيفة (تحتوي على ملفات مصدرية أساسية). يمكنك تشغيل `flutter create .` محليًا إذا رغبت بإنشاء مجلدات `android/` و `ios/` الكاملة من جهازك.
- تم إنشاء فرع: `feature/mobile-scaffold` لإضافة بقية الملفات والإعدادات بدون تغيير الفرع الافتراضي مباشرة.
